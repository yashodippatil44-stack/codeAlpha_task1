# Supermarket Sales EDA

Exploratory Data Analysis of supermarket sales data using Python.

## 📌 Objective

Analyze sales transactions to identify:

* Sales and product trends
* Customer purchasing patterns
* Branch and payment performance
* Relationships between variables
* Outliers and data-quality issues

## 🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Jupyter Notebook

## 📊 Dataset

**Supermarket Sales Dataset** by Aung Pyae.

The dataset contains 1,000 transaction records from three supermarket branches with customer, product, sales, payment, and rating information.

## 🔍 Analysis Covered

* Data exploration & cleaning
* Univariate and bivariate analysis
* Time-based analysis
* Correlation analysis
* Outlier detection
* Hypothesis testing
* Key findings and conclusions
